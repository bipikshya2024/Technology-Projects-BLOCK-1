# Part 3 – Component Investigation
Photograph and investigate the following components.

```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |The CPU executes program instructions, performs arithmetic and logical operations, and coordinates processing tasks. It is commonly referred to as the brain of the computer. |Clock speed (GHz), number of cores and threads, cache memory, and processor architecture. |
| RAM |RAM temporarily stores data and instructions that are actively used by the CPU. It provides fast access to information but loses its contents when the computer is switched off. |Capacity (GB), memory type (DDR4/DDR5), transfer speed (MT/s), and latency. |
| Storage |

Storage devices retain the operating system, applications, documents, and other data even when the computer is switched off. Common examples include Solid-State Drives (SSDs) and Hard Disk Drives (HDDs) |Storage capacity (GB/TB), device type (SSD/HDD), read/write speed, and interface (SATA/NVMe). |
| Motherboard |

The motherboard is the main circuit board that connects the CPU, RAM, storage devices, and other hardware components. It enables communication between these components. |Form factor (ATX/Micro-ATX), CPU socket, chipset, RAM compatibility, and expansion slots. |
| Power Supply |The PSU converts alternating current (AC) from the mains electricity supply into the direct current (DC) required by computer components. It distributes electrical power throughout the system. |Rated power output (watts), efficiency certification, voltage outputs, and available power connectors. |
| Cooling |The cooling system removes excess heat generated by components such as the CPU and GPU. It helps maintain safe operating temperatures and prevents thermal throttling or overheating. |Cooling method (air/liquid), fan size, fan speed (RPM), and cooling capacity. |
