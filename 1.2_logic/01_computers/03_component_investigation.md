

| Component | Function | Key Specification |
|---|---|---|
| CPU | Executes program instructions, performs calculations, and coordinates processing tasks. | Clock speed (GHz), number of cores and threads, cache memory, and processor architecture. |
| RAM | Temporarily stores data and instructions currently being used by the CPU. It loses its contents when the computer is switched off. | Capacity (GB), memory type (DDR4/DDR5), transfer speed (MT/s), and latency. |
| Storage | Permanently stores the operating system, applications, documents, and other files. Examples include SSDs and HDDs. | Capacity (GB/TB), storage type (SSD/HDD), read/write speed, and interface (SATA/NVMe). |
| Motherboard | Connects the CPU, RAM, storage devices, and other hardware components, allowing them to communicate. | Form factor (ATX/Micro-ATX), CPU socket, chipset, RAM compatibility, and expansion slots. |
| Power Supply | Converts mains AC electricity into DC power required by computer components. | Rated power output (watts), efficiency rating, voltage outputs, and power connectors. |
| Cooling | Removes excess heat from components to maintain safe operating temperatures and prevent overheating. | Cooling method (air/liquid), fan size, fan speed (RPM), and cooling capacity. |
