# Part 1 – Hardware vs Software

## Explain Hardware

Computer hardware refers to the physical components of a computer system that can be seen and touched. These components include the Central Processing Unit (CPU), Random Access Memory (RAM), Graphics Processing Unit (GPU), motherboard, power supply, cooling system, keyboard, monitor, printer, and mouse. Hardware performs different functions, such as processing data, storing information, accepting input, and displaying output. All these components work together to allow a computer to operate correctly and efficiently.

## Explain Software

Computer software is a collection of programs, instructions, and data that tells a computer how to perform specific tasks. Unlike hardware, software is not a physical component that can be touched. It allows users to perform activities such as writing documents, browsing the internet, editing images, and playing games. Software includes operating systems, such as Windows and Linux, and applications, such as LibreOffice Writer and Google Chrome. Hardware needs software instructions to perform useful tasks.

## How Do Hardware and Software Interact?

Hardware and software work together to make a computer function correctly. Software provides the instructions, while hardware carries out those instructions. For example, when a user types a document in LibreOffice Writer, the keyboard sends input to the computer, the CPU processes the instructions, and RAM temporarily holds the data being used. The monitor displays the document, while the storage device saves the file. The operating system and device drivers help coordinate communication between software and hardware. Without hardware, software cannot run, and without software, hardware cannot perform most useful computing tasks.
